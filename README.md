# THIS IS NOT A STANDALONE MOD
You'll need another mod to call the functions, a standalone version is planned.

## How to use
Get your Mod to create a PlayerPersistence object and call the functions `syncInventoryData`, `syncEnderChestData` , `syncPlayerCoordinates` to fetch data from the DB.  
To write to the DB use the functions `writeInventory`, `writeEnderChest`, `writePlayerCoordinates`.
